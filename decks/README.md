# Папка колод карт / Deck modules folder

Любой файл `.js`, добавленный в эту папку (`src/decks/`), **автоматически подхватывается игрой** и появляется в списке выбора колод!

Как это работает:
- **На GitHub Pages (`*.github.io`)**: приложение автоматически считывает содержимое папки `src/decks/` через GitHub Contents API, динамически загружает новые `.js` файлы и кэширует их для оффлайн-работы.
- **При локальном запуске / сборке Vite**: плагин автоматически обновляет `src/decks/manifest.json`.
- **На обычном статическом сервере**: приложение также проверяет `src/decks/manifest.json` и листинг директории `src/decks/`.

---

### Формат 1: Колода с готовыми карточками (4 слова на карту)
В такой колоде поддерживаются оба режима игры: и «Оригинальные карты», и «Случайная комбинация слов».

```javascript
export default {
  id: "custom_cards",
  name: {
    ru: "Моя колода карточек",
    en: "My Card Deck"
  },
  description: {
    ru: "Описание вашей колоды на русском языке.",
    en: "Description of your deck in English."
  },
  cards: [
    {
      id: "card-1",
      ru: ["Север", "Восток", "Юг", "Запад"],
      en: ["North", "East", "South", "West"]
    },
    {
      id: "card-2",
      ru: ["Огонь", "Вода", "Земля", "Воздух"],
      en: ["Fire", "Water", "Earth", "Air"]
    }
    // минимум 5 карт для раунда
  ]
};
```

---

### Формат 2: Колода из списка слов (массив слов без деления на карты)
Если колода содержит только массив слов, игра **автоматически включает режим «Случайная комбинация»** и блокирует режим готовых карт.

```javascript
export default {
  id: "custom_words",
  name: {
    ru: "Мой список слов",
    en: "My Word List"
  },
  description: {
    ru: "Просто массив слов, которые случайным образом перемешиваются по 4 на карту.",
    en: "Just a list of words automatically arranged into random 4-word cards."
  },
  // Двуязычный массив объектов:
  words: [
    { ru: "Космос", en: "Space" },
    { ru: "Океан", en: "Ocean" },
    { ru: "Вулкан", en: "Volcano" }
    // или просто массив строк: ["Космос", "Океан", "Вулкан", ...]
  ]
};
```
